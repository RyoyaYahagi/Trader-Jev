# Paper運用障害の表示

`codex/paper-dashboard-health`は、既存の画面デザインを維持して運用状態と見送り理由を追加する修正です。基点は既存のUI更新を含む`d29c713`です。自動Paperの修正は`codex/paper-decision-recovery`の`98c42ba`に分離しています。

ダッシュボードはSQLiteの`kind=runtime_health`記録から、正常応答・通信失敗・応答不正・価格期限切れ・判断期限切れ・価格更新失敗・条件未達を表示します。分析表には型・トレンド・継続性それぞれの信頼度と具体的な見送り理由を表示します。従来の記録に運用状態がない場合も読み込めます。秘密情報や生のエラー本文はAPIに返しません。

既存の未コミット変更4ファイルは、この修正に含めず保持します。運用専用cloneにはPaper判断の修正を配置し、ダッシュボードサービスは従来どおり開発用チェックアウトを読み込みます。GitHubではダッシュボードPRをdevelop向けに作成し、運用修正PRをその上に積みます。運用修正PRには未公開のGateway対応も含め、既存UIを維持します。
