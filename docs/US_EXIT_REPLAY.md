# 保存済み入口からの決済時間比較

米国株Paperの5分先の判断と、最大15分保有の損益は異なる評価対象です。
保有時間を短くすれば利益が改善するとは限らないため、同じ入口・数量・資金で
決済条件だけを変えて比較します。既定の運用設定は変更しません。

## 実行

このコマンドは保存された購入後の独立ポートフォリオと株価を使います。
Jevの再推論、OpenD接続、注文・口座APIの呼び出しはありません。
`replay_recorded_exit` は新規エントリーを作らず、決済も既存RiskEngineを通します。

```bash
PYTHONPATH=src python -m trader_jev.us_exit_replay_cli \
  --artifact /absolute/path/to/us-20261009-holdout \
  --output /absolute/path/to/new-exit-comparison \
  --holding-seconds 300 900
```

インストール後は `trader-jev-us-exit-replay` でも実行できます。
入力は `inputs/selection.json`、`inputs/selection-metadata.json` と
`replay-results.json`。元の市場台帳のパスはselection metadataから読み、
SQLiteを読み取り専用で開きます。一時ディレクトリへの固定パスには依存しません。
出力先は新しいディレクトリを指定し、過去の実験を上書きしません。

## 比較・検算

- 最も緩い保存済み信頼度基準で購入した入口を一度ずつ再利用します。
  厳しい基準での採否は元の結果を保持します。
- 原質問・回答・入口数量は変更せず、最大保有時間だけを変えます。
  損切り2%、利確3%、moomoo US Basic、片側10bpsのスリッページは固定です。
- 売却は部分約定を含めて追跡し、保有数量がゼロになるまで続けます。
  決済できない場合は未決済とし、完成した取引損益はnullです。
- 同じ株価更新時刻で内容が矛盾するsnapshotは、その時刻全体を除外します。
  raw SDKデータだけの差は除外理由にしません。除外数をケース別に保存します。
- 900秒の結果は以前の結果と照合します。株価品質に変更がないケースで不一致なら失敗。
  矛盾するsnapshotの除外で変わったケースは差分を明記します。
- 約定数量と、価格×数量−手数料をポートフォリオと照合します。
  `gross_quote_pnl_usd` はbid/askベースで、スプレッドはすでに含まれます。
  `net_pnl_usd = gross_quote_pnl_usd - fees_usd - slippage_cost_usd` を検算します。

## 2026-10-09の比較結果

2026-10-13に、改善版質問2.1の保存応答を使った39種類の入口を、
300秒・900秒で再生しました。追加モデル呼び出しは0件です。
ケースごとの延べ9時刻で矛盾を除外しましたが、900秒の全39取引は以前の損益と一致しました。

主標本180件、信頼度下限0.55では、両方とも15取引を決済しました。

| 最大保有 | 黒字／赤字 | bid/ask損益（USD） | 手数料 | スリッページ | 費用込み損益 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 5分 | 2／13 | -7.09 | 6.40 | 4.71661 | -18.20661 |
| 15分 | 4／11 | -4.60 | 6.39 | 4.71910 | -15.70910 |

0.40・0.50・0.60・0.65でも、主標本・補助標本それぞれで5分の合計損益が悪化しました。
短縮の有効性は確認できないため、この結果だけで15分を5分へ変更しません。
同時に、15分でも費用を引く前から赤字であり、費用だけを直せば利益になる結果ではありません。

## 解釈の限界

1営業日の結果を見た後の追加比較です。保有時間や信頼度の最適性は未確定です。
各入口は独立資金であり、連続運用・候補間の資金競合を再現していません。
新たなJevの売却判断も再生していません。

最大保有時間は、次の利用可能な保存quoteで決済する締切です。
記録間隔と部分約定による締切超過を保存し、ちょうど300秒の株価を作りません。
今回の超過は主標本の5分ケースで最大64秒、補助標本で最大181秒でした。
株価更新時刻に基づく比較で、元の受信・推論・処理遅延は再現しません。
このため、厳密な5分リターン予測の精度と同一視しません。

生成した `summary.json`、`exit-results.json`、独立SQLite台帳は実験用data配下へ保存し、
Gitには含めません。summaryには元の標本と再生結果のSHA256も記録します。
