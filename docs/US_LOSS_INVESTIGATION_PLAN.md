# 米国株Paperの赤字原因と改善検証計画

作成: 2026-10-13（Asia/Tokyo）。関連Issue: #21。この文書は計画のみで、設定・コードは変更していない。
文中の `data/` 配下のパスはローカルの実験データで、Gitには含めない。

## 1. 調査結果（前提）

### 赤字が出ている場所

- 本番Paper（`data/us_equity_paper.sqlite3`）は約定0件。10/1以降の判断はすべて `HOLD` / `NO TRADE`。
  - HOLDの約9割が `confidence_below_threshold`（旧質問セットで信頼度0.55未満）。
- 赤字は10/9の保存データ再生検証（`data/validation/us-20261009-holdout/report.md`）。
  主標本・信頼度下限0.55で15取引 −15.71 USD、全基準で赤字。

### 損失の内訳（入口が異なる39取引、合計 −36.50 USD）

| 要因 | USD | 割合 | 1往復あたり |
| --- | ---: | ---: | ---: |
| 手数料（moomoo 0.132%×2） | −15.97 | 44% | 約27bps |
| スリッページ（片側10bps×2） | −11.80 | 32% | 約20bps |
| bid/askスプレッド | −5.26 | 14% | 約9bps |
| 値動き（仲値） | −3.52 | 10% | 約−6bps |

- 費用だけで損失の約9割。ただし費用を除いても値動きはマイナスで、費用を直すだけでは黒字にならない
  （`us-20261009-horizon-comparison-v2/report.md` と一致）。
- スリッページを0にしても約 −24.7 USD で赤字。

### 根本原因

1. 往復費用 約56bpsに対し、15分で±55bps以上動く場面は全銘柄で19%しかない。
2. 39件中37件が最大保有15分の時間切れで決済。利確3%は0件、損切り2%は1件。損切り・利確が機能していない。
3. Jevの買いシグナルに優位性が見えない（主標本、15分後の仲値リターン平均）。

| グループ | 件数 | 平均 | 上昇割合 |
| --- | ---: | ---: | ---: |
| 0.55で買った場面 | 15 | −10.1bps | 60% |
| 買わなかった場面 | 155 | −8.0bps | 43% |
| 全銘柄の基準値 | 6,169 | +0.1bps | 51% |

| 形状 | 平均 |
| --- | ---: |
| MOMENTUM_BREAKOUT | −14.9bps |
| REVERSAL | −16.9bps |
| TREND_CONTINUATION | −7.5bps |
| NO_SETUP | +2.5bps |

上昇形状を見て買うと、15分以内に押し戻される傾向。1営業日・39取引のみで統計的には弱い。

### 使えるデータ

- 9/24〜10/12の12営業日。1日約350〜450ステップ（ほぼ1分ごと）、候補150〜200銘柄のbid/ask。
- Jev応答は10/7〜10/12に約4万件（大半が旧質問セット）＋10/9の2.1応答240件。

### Jevへの見立て

改善版2.1の回答は定義と240/240件で一致した。Jevは「今見えている値動きの形」の分類で、
数値特徴量から計算できる情報の言い換えに近い。予測力の上積みは期待しにくい。

## 2. 方針

- まずJevなしで「費用を超える値動きの偏りがあるか」を安く確かめる。
- Jevはその上に「上積みがあるか」だけを測る。
- モデル呼び出しは原則行わない。

## 3. 共通ルール（最初に固定し、途中で変えない）

- 費用: 手数料13.2bps×2、スプレッドは実測。スリッページは片側0／5／10bpsで計算し、採用判定は5bps、10bpsは参考。
- データ分割:
  - 探索: 9/24〜10/7、10/9（10/9は分析済みのため探索側）
  - 検証: 10/8、10/12、今後の新しい営業日。探索中は見ない。
- 指標: 1取引あたり費用控除後bps、日別平均、黒字日の割合、日単位ブートストラップの90%区間。
- 重複対策: 同じ銘柄は保有時間以上の間隔を空けて標本化。
- 最低件数: 検証5営業日以上かつ50取引以上。不足なら「保留」とし、稼働中サービスがデータを貯めるのを待つ。

## 4. 各Phaseと判定

### Phase 0: 準備（半日）

1. データ点検: 日別の銘柄数、quote間隔、欠損、矛盾snapshot（PR #29の除外処理を流用）。
2. 前向きリターン表: 時刻・銘柄・特徴量・bid/askごとに、15／30／60分後と引け前のリターン（仲値と売買可能価格の両方）。
3. 検算: 10/9の結果（0.55で買った15件の平均 −10.1bps 等）を再現。

→ 再現できなければ表の誤り。ここで止めて直す。

### Phase 1: Jevなしで優位性を探す（1〜2日、モデル費用0）

仮説は事前に絞り、区分は合計20程度まで（多重比較による偶然の当たりを避ける）。

- H1 押し戻し: 直近15〜60分の上昇・VWAP上方乖離が大きいとその後下がるか。売りから入らないので「下落後に買う」も確認。
- H2 時間軸: 保有を15分→30分→60分→引けまで延ばすと、値幅に対する費用比率が改善するか。
- H3 時間帯: 寄り後30分と引け前を除くと改善するか。
- H4 区分: レーン（momentum／breakout／reversal／liquid）別、前日比の大きさ別。

| 結果 | 次にやること |
| --- | --- |
| 1A 探索で費用控除後プラス、検証でも同符号でプラス | Phase 3へ（Phase 2も並行） |
| 1B 費用控除前はプラスだが費用を超えない | 「数十分の日中取引はこの手数料では勝てない」と結論。ユーザーが選ぶ: (a) 数日保有へ設計変更（日足データの入手先が必要、運用範囲も変わる）、(b) 手数料無料の日本株へ同じ枠組みを向ける、(c) 研究を止めデータ収集のみ継続 |
| 1C 費用控除前でも偏りなし | 優位性なし。Jev改善にも進まず、1Bの(a)〜(c)から選ぶ |
| 1D 探索でプラス、検証でマイナス | 過学習扱い。検証日を5営業日追加して1回だけ再判定。だめなら1C |

### Phase 2: Jevの上積み評価（1日、モデル呼び出しなし）

保存済み応答を前向きリターン表に結合する。

1. Jevの各スコアと15／30／60分後リターンの順位相関（日別に計算して平均）。
2. 同じ時刻・同程度の量的スコアの候補内で、Jev高評価群と低評価群のリターン差。
3. Jevの形状分類を数値ルールでどこまで再現できるか（一致率）。

| 結果 | 次にやること |
| --- | --- |
| 2A 日ごとに一貫してプラス、上位群が対照より+20bps以上、検証日でも維持 | Jevを絞り込み条件として残し、Phase 3のルールに重ねる |
| 2B 相関ほぼ0、または数値ルールで代替可能 | 売買判断からJevを外す（最も起こりやすいと想定） |
| 2C 一貫してマイナス | 反転して使わない（効いているのは形状自体なのでPhase 1のH1で扱う）。2Bと同じ扱い |
| 2D 符号がばらつく、件数不足 | 標準はJevなし。データが貯まったら再評価 |

### Phase 2.5: Jevの性能向上（条件付き、1回だけ）

- 実施条件: Phase 1が1Aまたは1B、かつPhase 2が2Bの場合のみ。1Cなら実施しない。
- 理由: 現在の質問は形状の説明。伸ばせる余地は「数値化しにくい文脈判断を将来予測として直接問う」ことだけ。
- 内容: 「今後30分で費用（約0.5%）を超えて上がる見込み」を問う1問に絞る。探索期間から固定した約300件で評価し、検証標本で確認。
- 予算: 質問設計はやり直し込みで2回まで。費用は前回実績から0.1 USD前後。
- 打ち切り: 上位群が数値ルール単独より費用控除後で改善しなければ打ち切り、「Jevは売買判断に使わない」を確定方針にする。

### Phase 3: 出口設計とルール化（1Aのときだけ）

- 損切り・利確を保有時間内の値幅に合わせる（例: 直近ボラティリティの倍数）。最大保有はPhase 1で良かった時間軸。
- 組み合わせは3×3程度。PR #29の再生基盤で探索期間→検証期間。
- 連続運用を再現: 最大3銘柄の資金競合、候補順位、記録間隔による遅延。

| 結果 | 次にやること |
| --- | --- |
| 3A 検証でスリッページ5bpsでもプラス、10bpsでも大きく崩れない | Phase 4へ |
| 3B 0bpsでしかプラスにならない | 費用依存が大きすぎるので不採用。1Bと同じ扱い |

### Phase 4: Forward Paper（10営業日）

- 現運用は変えず、新しい仮想ポートフォリオとして並走（同じ株価イベントを分岐する既存の仕組み）。実注文なし。
- 合格基準を事前固定: 費用控除後損益プラス、Phase 3の見込み範囲内、運用障害なし。

| 結果 | 次にやること |
| --- | --- |
| 4A 合格 | 期間延長、または資金条件の比較へ |
| 4B 見込み範囲内だがマイナス | 10営業日延長して再判定（1回まで） |
| 4C 見込み範囲を下回る | 再生と実運用の差（遅延・約定仮定）を調査し、説明できなければ戦略を捨てる |

## 5. やらないこと

- 信頼度下限・保有時間の細かい調整（優位性がない状態では赤字幅が変わるだけ）。
- 2.1質問セットの本番反映（優位性確認前に約定を増やすと損失が増えるだけ）。
- Jevの評価を反転させて使うこと。

## 6. 止めどころ

- Phase 0〜2は数日、モデル費用ほぼ0。
- 1Cかつ2Bなら「この時間軸・候補群・費用ではやらない」と結論して終了。次の方向（数日保有、日本株、データ収集のみ）をユーザーが選ぶ。
- 検証データ不足で保留なら約5営業日待って再判定。
