## Gate項目との対応

- same dataset + config + seed: 同一JSONLを2回読み、同一ReplayConfig・seedで同一payload列を確認
- deterministic event ordering: `received_at`順を確認。`event_time`が先行する遅延Tradeは`received_at`時点まで出現しない
- future leakage: ReplayEngineのfuture event拒否、FeatureEngineのfuture event除外、Newsのavailability境界、Prediction metadata検証を確認
- timestamp semantics: market eventは`received_at`、Newsは`published_at`・`first_seen_at`・`received_at`をavailabilityとして扱う
- duplicate / out-of-order / missing: `DataQualityReport`で重複1件、逆順1件、欠損interval 1件を検出
- missing / stale handling: 欠損intervalをreportし、stale market dataをRiskEngineが拒否
- wall clock isolation: strategy/replay/feature/pipeline/risk対象モジュールに直接のsystem wall clock参照なし。ReplayClock注入を使用
- fixture round trip: JSONL読込 → Parquet保存 → Replay → Parquet再読込のpayload一致を確認

## Known limitations
